# Canadian Wildfire Smoke — Impact on the Chicago Area

A live, auto-updating dashboard tracking Canadian wildfire smoke and its impact on Chicago-area air quality.

- **Smoke plume extent** (animated, day by day) and **satellite fire detections** — NOAA Hazard Mapping System
- **Chicago-area PM2.5/AQI readings** — EPA AirNow API

Rebuilds automatically once a day via GitHub Actions, showing a rolling 8-day window.
